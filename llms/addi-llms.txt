# Addi

> Addi is a Colombian buy-now-pay-later (BNPL) fintech (founded 2018) that lets shoppers split purchases into installments using only a national ID — no credit card. Merchants integrate Addi as a checkout payment method via first-party e-commerce plugins and a REST API secured with Auth0 OAuth2 client-credentials. Addi serves 2M+ customers and tens of thousands of merchants across Colombia and Brazil, and is regulated by the Superintendencia Financiera de Colombia.

## APIs

- [Addi Credit & Checkout API](https://api-docs-sandbox.addi.com/auth/): Create BNPL credit applications at checkout; Auth0 OAuth2 client-credentials. Production host https://api.addi.com
